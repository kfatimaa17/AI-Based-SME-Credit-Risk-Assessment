# AI-Based SME Credit Risk Assessment

## Project Overview

AI-Based SME Credit Risk Assessment is a proposed machine learning-based system designed to support the credit evaluation of Small and Medium Enterprises (SMEs).

The project aims to analyze relevant financial, credit, and business information and support faster and more informed lending decisions.

## Problem Statement

Traditional SME credit assessment can be time-consuming and heavily dependent on manual evaluation. Limited financial information can also make it difficult to accurately assess the creditworthiness of small businesses.

## Proposed Solution

The proposed system will use Artificial Intelligence and Machine Learning techniques to analyze SME-related data, predict credit risk, and classify applicants into different risk categories.

## Objectives

- Reduce the manual effort involved in credit assessment.
- Analyze relevant SME financial and credit information.
- Predict credit risk using machine learning.
- Generate a risk score and risk category.
- Support lenders in making faster and more informed decisions.

## Project Modules

### 1. Data Collection and Preprocessing
Collecting, cleaning, and preparing SME-related data for analysis.

### 2. AI-Based Credit Risk Analysis
Applying machine learning algorithms to analyze the processed data and predict credit risk.

### 3. Loan Decision Support
Classifying applicants into low, medium, or high risk and providing a loan recommendation.

### 4. Monitoring and Reporting
Monitoring credit-related information and generating useful reports.

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Streamlit
- Matplotlib / Plotly
- Git & GitHub

## Dataset

The current prototype uses a synthetic dataset created for academic development and testing. It contains 1,200 records with relevant credit-risk features.

The dataset does not represent real bank or customer data.

## System Flow

SME Data → Data Preprocessing → Machine Learning Model → Risk Prediction → Risk Category → Loan Decision Support

## How to Run

Install the required Python libraries:

```bash
pip install -r requirements.txt
```

Then run the Streamlit application:

```bash
streamlit run app.py
```
